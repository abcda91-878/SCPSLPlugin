# SCP‑181 Exiled 插件

基于 Exiled v9.14.2 开发，实现 SCP‑181「幸运儿」角色。

## 📋 插件介绍

为 SCP: Secret Laboratory 添加 SCP‑181 自定义角色。
SCP‑181 拥有被动概率扭曲效果：处境安全时获得幸运加成。

## ✨ 功能特性

- 🔮 **幸运模式:**
  - 规避部分致命伤害
  - 有概率捡取到优质物资
  - 意外事件倾向对自身有利

## ⚙️ 配置项

> 插件加载后不会在 `EXILED/configs` 生成配置文件

## 📦 安装方式

1. 将 `SCP181.dll` 放入服务器 `EXILED/plugins` 文件夹
2. 启动服务器，不会自动生成配置

## ℹ️ 版本信息

- Exiled 建议版本：***v9.14.2***
- 建议游戏版本：***SCP:SL 14.2.7***
